 ---> Python gives every file a variable called "__name__":

 How the file is used	         Value of __name__	         Guard block runs?
Run directly: python utils.py	     "__main__"	                   Yes
Imported: from utils import ...	       "utils"	                    No


The guard means "run this code only if this file is the one being executed, not if it was imported." 
It lets one file work both as a reusable module (import its functions) 
and as a standalone script (run it directly) without side effects.
